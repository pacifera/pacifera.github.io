02 / MEAL JOURNAL

한 끼 기록하기

내가 먹은 양을 적으면 AI가 균형을 살펴보기 쉬워요. 정확히 모르면 ‘대략’이라고 표시하세요.

식품군 표시 · 선택, 직접 체크

먹은 식품군을 직접 표시합니다. 체크하지 않은 항목은 ‘안 먹음’이 아니라 ‘미표시’입니다. 영양량을 계산하거나 충분한 섭취로 판정하지 않습니다.

수량 미확인 재고는 자동 차감할 수 없습니다. 먼저 실제 잔량을 입력하세요. 여럿이 먹었다면 재고 차감에는 전체 조리 사용량, 위 식사 구성에는 본인이 먹은 양을 적으세요.

기록 수정은 메뉴·일시·메모만 변경합니다. 이미 차감한 재고는 다시 차감하거나 되돌리지 않습니다. 사용량을 잘못 적었다면 재고에서 실제 잔량을 수정하세요.

식사를 실제로 마친 뒤 기록하세요. 차감하는 경우 저장 전 사용량을 확인합니다.

먹은 기록

기록이 없는 식사는 ‘안 먹음’으로 판단하지 않습니다. 이 화면은 칼로리나 영양성분을 자동 계산하지 않습니다.

03 / ASK YOUR AI

기록으로 물어보기

조건을 선택하면 붙여넣을 글이 만들어집니다. 복사해 이 대화나 사용하는 AI에 전달하세요.

기존 생활 조건은 반복하지 않고 재고·식사·질문만 전달합니다.

‘새 대화 시작’에서는 선택 기간 전체를 전달합니다. 기간 밖 기록은 제외하되, 이미 전달한 식사의 날짜가 기간 밖으로 수정된 경우 정정분을 함께 보냅니다.

다음 식사 조건 · 추천 요청에 적용

사이트에서 AI를 호출하거나 데이터를 자동 전송하지 않습니다. 복사·붙여넣기 후 AI에서 답변을 받습니다.

AI에 전달할 내용

재고는 항상 최신 전체 목록으로 교체합니다. 식사는 고유 ID로 추가·수정·삭제를 구분해 중복 누적을 막습니다. AI가 실제 반영했는지는 사이트에서 확인할 수 없습니다.
복사가 차단되면 글을 선택해 직접 복사하거나 TXT 파일로 저장하세요. AI 답변은 재고에 자동 반영되지 않습니다.
복사·다운로드·인쇄 후 같은 AI 대화에 실제로 전달한 뒤 완료 표시를 누르세요. 버튼을 눌러야 이번에 보낸 식사를 다음 업데이트에서 제외합니다. 복사만으로는 전달 처리하지 않습니다. 직접 복사하려면 TXT 저장이나 인쇄로 전달본을 먼저 확정하세요.
전달 기준은 AI 대화 하나에만 사용하세요. 다른 대화로 옮길 때는 ‘새 AI 대화 시작’을 선택해 먼저 전체 설정을 전달하세요. 완료 표시 후 새 기준으로 전환됩니다. 여러 AI 대화별 기준 관리는 지원하지 않습니다.




04 / BACKUP & PREFERENCES
백업과 기본 원칙
구매 날짜, 식사 기록, 사용 내역, 기본 선호를 JSON 파일로 저장합니다. 이전 버전의 재고 백업도 불러올 수 있습니다. 다른 기기로 옮길 때 백업을 이용하세요.


먹었던 메뉴도 다시 추천 가능
식사 기록은 영양 균형 점검에 활용하며, 메뉴 제외 목록으로 사용하지 않습니다. 이전의 반복 메뉴 제외 조건도 AI 전달문에서 해제합니다.


저장과 사용 안내
  1. 자동 저장: 재료 추가·수정·사용, 식사 기록을 확정하면 이 브라우저에 저장합니다. 입력 중인 미저장 폼은 닫으면 사라집니다. 저장 실패 시 상단에 알립니다.
  2. 기기별로 따로: 로그인·클라우드 동기화는 없습니다. 브라우저 데이터 삭제, 시크릿 모드, 파일 위치 또는 웹주소 변경에 따라 기록이 유지되지 않을 수 있습니다.
  3. 구매 날짜: 처음 등록된 25가지 재료의 날짜는 비어 있습니다. 구매일을 알고 있을 때만 입력하세요. 같은 재료의 다른 구매 건은 별도 행으로 관리합니다.
  4. 수량과 차감: kg↔g, L↔ml만 환산합니다. 한 개·한 캔의 무게는 임의로 계산하지 않습니다. 수량을 모르면 재고를 실제 잔량으로 수정한 뒤 사용하세요.
  5. 식사 기록: 메뉴·먹은 양·메모를 직접 기록합니다. 식품군 체크는 자기 기록이며 영양 충분성 판정이 아닙니다. 식사 기록 수정·삭제는 이미 차감된 재고를 되돌리지 않습니다.
  6. 영양 상담: 선택 기간의 기록을 AI에 붙여넣어 단백질·채소·식품 다양성 등을 정성적으로 점검하세요. 기록되지 않은 식사와 정확한 영양량은 판단하기 어렵습니다. ‘같은 AI 대화 이어가기’는 생활 조건을 반복하지 않습니다. 처음 사용하거나 새 채팅으로 옮길 때는 ‘새 AI 대화 시작’을 선택하세요.
  7. 식사 업데이트: 전달한 식사와 같은 ID는 덮어쓰고 새 ID만 추가하도록 안내합니다. 실제 붙여넣기 후 완료 표시를 눌러야 전송 기준이 갱신됩니다. 기준 초기화는 재고·식사를 삭제하지 않지만 식사 전체가 다시 전달 대상이 됩니다. AI가 이전 맥락을 놓쳤다면 전체 기간·기본 원칙을 다시 전달하세요.
  8. 다른 탭: 여러 탭에서 동시에 수정하지 마세요. 저장 충돌이 감지되면 새로고침 후 최신 자료로 다시 작업해야 합니다.


인터넷 주소로 접속하려면?
이 HTML 파일은 브라우저에서 열 수 있는 웹페이지이며, 아직 온라인 게시된 사이트는 아닙니다. 정적 호스팅에 파일을 올리면 주소로 접속할 수 있습니다. 첫 화면 파일명은 index.html로 두면 편합니다. 별도 빌드나 서버 실행은 필요하지 않습니다.
게시해도 재고는 각 브라우저에 저장되며 서로 동기화되지 않습니다. 파일 안에는 기본 재료 목록이 포함되어 있으나, 이후 입력한 개인 기록은 백업 파일이나 복사한 글을 공유하지 않는 한 외부로 전송하지 않습니다.


식품 보관에 관하여
소비기한은 제품 포장과 개봉 후 보관 지침을 우선합니다. 구매 날짜만으로 안전한 보관 기간을 정하지 않습니다. 냉장고의 냉각 성능을 모르면 안전하다고 단정하지 마세요. 밥·달걀·생선 등을 넣은 도시락은 빠르게 열을 빼 냉장하고, 이동 중에는 보냉백·아이스팩을 사용하세요. 상온에 오래 두며 완전히 식히는 방식은 피하세요.
